## 来源与版权合规

本知识库数据来源均为**团队原创 + 公开国家标准节选 + 公共教材公开目录二次加工**，符合比赛版权要求：

1. **团队原创（占比约 75%）**：依据《工业机器人操作与编程》《PLC 应用技术》等高职高专公开教材（职业教育国家规划教材目录内公开版本）的知识框架进行**二次整理与原创化表述**，避免原文抄袭。
2. **国家标准（节选关键术语，约 20%）**：
   - GB/T 12642-2013《工业机器人 性能规范及其试验方法》（公开可查术语部分）
   - GB/T 20721-2006《自动控制的可编程控制器 第1部分：通用信息》
   - GB/T 33000-2016《企业安全生产标准化基本规范》中"机器人安全"相关条款
3. **公共领域知识（约 5%）**：Wikipedia / 百度百科公开词条（如 Modbus、PLC、工业机器人分类）的术语级表述，已做二次改写与扩展。

**合规声明**：未使用任何未授权的商业付费课程视频、付费电子教材或闭源培训资料。团队原创内容允许比赛期间与赛后长期使用，公开标准部分严格遵守"合理引用（fair use）"仅截取定义与术语不超过全文 10%。

## 知识点覆盖范围（6 大模块 × 46 kp）

对应 `kp_taxonomy.json`：

1. **工业机器人基础**（kp01～kp01e，6 个 kp）：定义、分类、技术参数、安全规范、本体结构、末端执行器
2. **工业机器人坐标系与运动学**（kp02/kp12/kp12a-d/kp15/kp15a，8 个 kp）：坐标系变换、TCP 标定、正反运动学、D-H、路径规划、奇异位形
3. **PLC 编程基础**（kp03/kp03a-b/kp22/kp22a-d，8 个 kp）：原理/硬件/DI-DO/AI-AO/梯形图/STL-SST/SFC/调试
4. **传感器与检测技术**（kp04/kp04a-e，6 个 kp）：分类/接近开关/安全/编码器/温压力流量/视觉
5. **工业互联网与通信**（kp05/kp05a-e，6 个 kp）：分层/Modbus/PROFINET/OPC UA/IIoT/安全
6. **智能制造系统集成**（kp06/kp06a-e/kp18/kp18a，8 个 kp）：产线组成/机器人PLC协同/气动/仓储/MES-ERP/数字孪生/离线编程/节拍分析

## 目录结构

```
kb/
├── kp_taxonomy.json          # 知识点层级 + kp_index（46 kp）
├── source/
│   └── README.md             # 本文件：构建说明、版本、来源、统计
├── chunks/
│   ├── build_chunks.py       # 240 条 chunk 生成脚本（可重复执行）
│   └── kp_chunks.jsonl       # 240 条 chunk 原始数据（JSONL 格式）
└── scripts/
    ├── ingest.py             # 一键：kp_chunks.jsonl → kb_chunk 表
    └── eval_coverage.py      # 覆盖率自检：46 kp → 95.7% ≥ 90% ✅
```

## 使用方式

```bash
# 1. 切分（如果要重新生成 240 条 chunk）
python -m backend.b_学情数据.kb.chunks.build_chunks

# 2. 入库到 kb_chunk 表
python -m backend.b_学情数据.kb.scripts.ingest

# 3. 覆盖率自检
python -m backend.b_学情数据.kb.scripts.eval_coverage
# Expected: coverage = 0.957, missing = ["kp05e", "kp12d"]
```
