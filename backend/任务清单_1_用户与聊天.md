## 涉及文件
- `backend/公共/auth_middleware.py` (新建)

## 描述
为 B / C / D 提供统一的"解析 token → userId"能力，**所有业务接口**都依赖它。

> 鉴权过程中需要查 `1_用户与聊天/` 的 User 表。中间件通过调用 A 暴露的 `get_user_by_id` 函数读取（**不**直连 A 的数据库），所以依赖 A-01。

## 验收标准
- [ ] 提供 `get_current_user(request) -> dict` 函数，返回 `{userId, name, role}`
- [ ] 提供装饰器 `@require_auth` 供路由使用
- [ ] 缺失 / 过期 token 时抛 `AuthError`
- [ ] 单元测试覆盖正常 / 过期 / 无效三种情况
- [ ] 在群里公告接口签名，B/C/D 同步

## 接口契约
```
请求头：Authorization: Bearer <token>
返回  ：dict  {"userId": "u001", "name": "张三", "role": "student"}
错误  ：401 {"code": 401, "message": "未登录或token过期"}
```
