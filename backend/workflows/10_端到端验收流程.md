## 步骤 4：实现失败处理

**输入**：3 个指标值

**操作**：
```python
if hallucination >= 0.05 or accuracy < 0.85 or coverage < 0.90:
    raise QualityError(
        f"3 项硬指标未达标：幻觉率={hallucination:.2%}, "
        f"准确率={accuracy:.2%}, 覆盖率={coverage:.2%}"
    )
```

**关键点**：
- **必须抛异常**（**不要**只 print）
- 异常信息含 3 个数值
- exit code = 1（让 CI / GitHub Actions 能识别）

**输出**：1 个 `QualityError` 类 + 抛异常的逻辑

**验证**：
- [ ] 故意让某个指标不达标 → 脚本 exit 1
- [ ] 异常信息能在终端看到

**失败处理**：未抛异常 → 检查 if 条件是否正确

## 步骤 6：加进 CI（GitHub Actions）

**输入**：脚本 + 仓库

**操作**：`.github/workflows/quality_check.yml`
```yaml
name: Quality Check
on: [push, pull_request]
jobs:
  quality:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with:
          python-version: '3.10'
      - run: pip install -r backend/requirements.txt
      - run: cd backend && python -m a_用户与聊天.quality_check
```

**输出**：1 个 CI 配置

**验证**：
- [ ] push 后 GitHub Actions 自动跑 quality_check
- [ ] PR 页面能看到 ✅ 或 ❌

**失败处理**：CI 失败 → 群里讨论，**不要** disable CI
