## 步骤 3：实现"主循环 + retry 逻辑"

**输入**：步骤 1 + 2 的骨架

**操作**：

```python
def orchestrate(studentId, resource_type):
    traceId = generate_trace_id()
    emit_agent_start(traceId, "orchestrator", "start", {...})
    
    # 1. B-05 学情诊断
    diagnosis = safe_call(
        lambda: B05_diagnose(studentId, kp_list),
        fallback=DEFAULT_DIAGNOSIS,
        timeout=5
    )
    emit_agent_result(traceId, "diagnosis", "B-05", diagnosis)
    
    # 2. C-04 + D-06 retry 循环
    resource = None
    audit = None
    for retry in range(2):  # 最多 2 轮
        resource = C04_generate_resource(studentId, diagnosis, resource_type)
        emit_agent_result(traceId, "expert", "C-04", resource)
        
        audit = D06_audit(resource, resource.cited_chunks)
        emit_agent_audit(traceId, audit)
        
        if audit.decision == "pass":
            break
        elif audit.decision == "fail":
            emit_agent_debate(traceId, ["expert", "auditor"], "low_score")
            break
        # retry 情况：把 suggestions 回灌给 C-04
        diagnosis = apply_audit_suggestions(diagnosis, audit.suggestions)
    
    emit_agent_final(traceId, ok=(audit.decision == "pass"), resource=resource)
    return resource
```

**输出**：完整的 retry 循环

**验证**：
- [ ] retry 不会超过 2 次（**必须**有 `for retry in range(2)`）
- [ ] fail 情况触发 debate
- [ ] 异常情况走 fallback

**失败处理**：死循环 → 检查 retry 上限 + break 条件

## 步骤 4：实现"异常处理矩阵"

**输入**：[`prompts/13_协同编排器_提示词.md`](../prompts/13_协同编排器_提示词.md) 第 5 节

**操作**：把异常处理矩阵**逐条**写成 try/except

```python
def safe_call(fn, fallback, timeout):
    try:
        return fn_with_timeout(fn, timeout)
    except TimeoutError:
        return fallback
    except Exception as e:
        log_error(e)
        return fallback
```

**输出**：1 个 `safe_call` 工具函数

**验证**：
- [ ] 矩阵中每条异常都有对应处理
- [ ] fallback 不会是 None（**必须**有默认值）

**失败处理**：fallback 缺失 → 用最简单的默认资源（如"暂无推荐"）
