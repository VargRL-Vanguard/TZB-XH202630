## 第一部分：B-06 知识库切片

### 步骤 1：选定垂直领域

**输入**：领域选择

**操作**：
- 选 **1 个**垂直领域（**不要**贪多）
- 推荐：智能制造 / 工业机器人 / PLC / 工业互联网
- 至少 3 份原始资料，每份 ≥ 5000 字

**输出**：领域选定 + 资料清单

**验证**：
- [ ] 资料放到 `backend/b_学情数据/knowledge_base/raw/`
- [ ] 资料覆盖核心概念 + 实操 + 案例

**失败处理**：资料不够 → 找团队一起收集，**不要**让 AI 自己"编"内容

---

### 步骤 2：设计知识点体系

**输入**：原始资料

**操作**：写 `backend/b_学情数据/knowledge_base/kp_taxonomy.json`

**严格规则**（**AI 必须遵守**）：
- **核心知识点数 ≥ 30**
- 每个 kp 必须有：`id` / `name` / `description` / `difficulty` / `parent_id` / `related_kps`
- `id` 格式：`kp_NNN`（3 位数字）
- `difficulty` 范围 1-5
- 父子关系用 `parent_id`

**模板**（直接用）：
```json
{
  "domain": "工业机器人",
  "version": "1.0",
  "kps": [
    {
      "id": "kp_001",
      "name": "机器人坐标系",
      "description": "...",
      "difficulty": 2,
      "parent_id": null,
      "related_kps": ["kp_002"]
    }
  ]
}
```

**输出**：1 个 `kp_taxonomy.json`

**验证**：
- [ ] `len(kp_taxonomy["kps"]) >= 30`
- [ ] 所有 `id` 唯一
- [ ] `parent_id` 引用的 id 必须存在

**详细模板**：[`prompts/20_知识库切片_提示词.md`](../prompts/20_知识库切片_提示词.md) 第 4 节

**失败处理**：kp 数 < 30 → 拆分更细（不要让 AI "合并" kp）

---

### 步骤 3：切片

**输入**：kp_taxonomy + 原始资料

**操作**：写脚本 `backend/b_学情数据/knowledge_base/split.py`，把资料切成 chunks

**严格规则**（**AI 必须遵守**）：
- **切片数 ≥ 200**
- 每片 **200-500 字**（**不要**超过 500）
- 每片必须有：`chunk_id` / `content` / `source` / `kp_tags` / `difficulty` / `word_count`
- **不要**从段落中间劈开（保持语义完整）
- **不要**让 AI "生成"切片内容（**只切不编**）

**切片策略**（推荐）：
- 段落切分（按 H2 / H3 标题）
- 长度超 500 字 → 拆分（按句号 + 关键词）
- 每片至少 1 个 `kp_tags`（人工 / LLM 辅助标注）

**输出**：≥ 200 个 JSON 文件

**验证**：
- [ ] `ls knowledge_base/chunks/ | wc -l` ≥ 200
- [ ] 每片 word_count 在 [200, 500]
- [ ] 每片至少 1 个 kp_tag

**失败处理**：切片太碎 → 合并相邻同主题段落

---

### 步骤 4：写自检脚本

**输入**：chunks + kp_taxonomy

**操作**：`backend/b_学情数据/knowledge_base/eval_coverage.py`

**严格规则**：
- 必须输出：总 kp 数 / 已覆盖 kp 数 / 覆盖率 / 未覆盖 kp 列表
- 覆盖率 < 90% → **抛异常**（exit 1）

**模板**（直接抄 [`prompts/20_知识库切片_提示词.md`](../prompts/20_知识库切片_提示词.md) 第 7 节）

**输出**：1 个可运行的脚本

**验证**：
- [ ] `python eval_coverage.py` 退出码 0
- [ ] 输出 "覆盖率: 0.92..."（≥ 0.90）
- [ ] `uncovered` 列表 < 3 项

**失败处理**：覆盖率 < 90% → 看 `uncovered` 列表，给这些 kp 补切片

### 步骤 8：校验

**输入**：3 个 JSON + kp_taxonomy

**操作**：
1. 写 `backend/b_学情数据/test_profiles/validate.py`：
   ```python
   import json
   from pathlib import Path
   
   kp_ids = {kp["id"] for kp in json.loads(Path("knowledge_base/kp_taxonomy.json").read_text())["kps"]}
   
   for p in Path("test_profiles").glob("*.json"):
       profile = json.loads(p.read_text())
       for kp in profile["expected"]["weakKPs"]:
           assert kp in kp_ids, f"{p.name}: weakKPs {kp} 不在 kp_taxonomy 中"
       print(f"✅ {p.name}")
   ```

**输出**：1 个校验脚本

**验证**：
- [ ] `python validate.py` 退出码 0
- [ ] 输出 3 行 ✅

**失败处理**：weakKPs 引用不存在 → 改用 kp_taxonomy 中实际存在的 id
