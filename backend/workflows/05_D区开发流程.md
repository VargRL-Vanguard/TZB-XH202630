### 4.2 完整流程

```python
def orchestrate(studentId, resource_type):
    traceId = generate_trace_id()
    emit_agent_start(traceId, "orchestrator", "start", {...})
    
    # 1. B-05 学情诊断
    diagnosis = B05_diagnose(studentId, kp_list)
    emit_agent_result(traceId, "diagnosis", "B-05", diagnosis)
    
    # 2. C-04 领域专家生成（retry 循环）
    for retry in range(2):
        resource = C04_generate_resource(studentId, diagnosis, resource_type)
        # 3. D-06 审核
        audit = D06_audit(resource, cited_chunks)
        emit_agent_audit(traceId, audit)
        if audit.decision == "pass":
            break
        elif audit.decision == "fail":
            emit_agent_debate(...)
            break
    
    emit_agent_final(traceId, ok=True, resource=resource)
    return resource
```

### 4.3 异常处理

**详细步骤**：[`workflows/07_协同编排开发流程.md`](file:///d:/TZB/TZB-XH202630/backend/workflows/07_协同编排开发流程.md)

- [ ] 异常情况都有兜底
