## 步骤 7：完成 B-06 知识库切片（⭐⭐⭐ 9-5 必交）

**输入**：原始资料（PDF/MD）

**操作**（**严格按顺序**）：

### 7.1 准备原始资料

- 收集 ≥ 1 个垂直领域的资料（推荐：智能制造 / 工业机器人 / PLC / 工业互联网）
- 放到 `backend/2_学情数据/knowledge_base/raw/`
- 至少 3 份文档，每份 ≥ 5000 字

### 7.2 设计知识点体系

- 创建 `kp_taxonomy.json`，含 **≥ 30 个 kp**
- 每个 kp 含：`id` / `name` / `description` / `difficulty` (1-5) / `parent_id` / `related_kps`

### 7.3 切片

- 创建 `chunks/` 目录
- **≥ 200 个 JSON 切片**
- 每片 200-500 字
- 每片含：`chunk_id` / `content` / `source` / `kp_tags` / `difficulty` / `word_count`

### 7.4 跑覆盖率自检

- 写 `eval_coverage.py`（参考 [`prompts/20_知识库切片_提示词.md`](../prompts/20_知识库切片_提示词.md) 第 7 节）
- `python eval_coverage.py` → 输出 **覆盖率 ≥ 90%**

### 7.5 暴露对外函数

```python
# backend/2_学情数据/kb/service.py
def list_kb_chunks_by_kp(kp_id: str, top_k: int = 5) -> List[dict]: ...
```

**详细步骤**：[`workflows/09_知识库与画像流程.md`](file:///d:/TZB/TZB-XH202630/backend/workflows/09_知识库与画像流程.md)

**输出**：1 个 `kp_taxonomy.json` + 200+ chunks + 1 个自检脚本

**验证**：
- [ ] `python eval_coverage.py` 输出覆盖率 ≥ 0.90
- [ ] `from backend.2_学情数据.kb.service import list_kb_chunks_by_kp` 能用
- [ ] C-04 领域专家 Agent 能检索到

**失败处理**：覆盖率 < 90% → 补充缺失 kp 的 chunks（看 `uncovered` 列表）
