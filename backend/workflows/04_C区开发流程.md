```python
def generate_resource(studentId, diagnosis_result, resource_type):
    # 1. 调 B 区 list_kb_chunks_by_kp(kp) 检索知识库
    # 2. 拼 prompt（强制只能引用 chunks）
    # 3. 调 D 区 ai_service 生成
```
