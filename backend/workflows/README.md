# 工作流程参考库（**步骤式 checklist，防 AI 幻觉**）

> **本目录的存在原因**：AI 在帮成员写代码时，**最容易在"下一步该做什么"上产生幻觉**。
> 这里把每个常见工作场景都拆成"步骤式 checklist"，每一步都明确"输入 → 操作 → 输出 → 验证"。
> 团队成员和 AI **严格按本目录的步骤执行**，不允许跳步或自由发挥。

---

## 使用方式

1. **找到当前任务对应的工作流程**（见下表）
2. **按步骤顺序执行**（不要跳步）
3. **每步完成后做"验证"**（不打勾 = 视为没做完）
4. **遇到"失败处理"分支** → 按提示走，不允许静默忽略

## 文档结构（每份流程文档都长这样）

```text
# 工作流程 NN：标题

## 前置条件
- 必须先完成什么
- 必须有什么依赖

## 步骤 1：xxx
**输入**：...
**操作**：...
**输出**：...
**验证**：...
**失败处理**：...

## 步骤 2：xxx
...

## 验收清单
- [ ] ...
```

## 与提示词库的关系

- **提示词库**（`prompts/`）告诉 AI"项目是什么 + 你要做什么"
- **工作流程库**（`workflows/`，本目录）告诉 AI"**怎么做**，按步骤来"

**两者必须配套使用**：
- 先让 AI 读 `prompts/0X_成员X_xxx_提示词.md` 理解"做什么"
- 再让 AI 读 `workflows/0X_X区开发流程.md` 理解"怎么做"
- **不要跳过工作流程直接让 AI 自由发挥**（这是幻觉的源头）
