## 步骤 3：完成 A-01 用户注册/登录

**输入**：A-00 + S-01 完成

**操作**：
1. 创建 `backend/a_用户与聊天/auth/service.py`（register / login / verify_token）
2. 创建 `backend/a_用户与聊天/auth/router.py`（FastAPI / Flask 路由）
3. 暴露 3 个接口：
   - `POST /api/auth/register` `{username, password, email}` → `{token, userId}`
   - `POST /api/auth/login` `{username, password}` → `{token, userId}`
   - `POST /api/auth/verify` `{token}` → `{userId, valid}`

**输出**：3 个可调用的认证接口

**验证**：
- [ ] 用 curl / postman 跑通 register → login → verify 3 步

- [ ] 密码用 bcrypt / argon2 哈希（**不要**明文存）

**失败处理**：JWT 报错 → 检查 `JWT_SECRET` 是否在 `公共/config.py` 加载

## 步骤 7：完成 A-04 WebSocket 5 类事件（⭐夺奖核心）

**输入**：A-00

**操作**（**严格按顺序**）：

### 7.1 创建 `backend/a_用户与聊天/ws/manager.py`

- 维护 `connections: Dict[userId, WebSocket]`
- 函数：`connect(userId, ws)` / `disconnect(userId)` / `send_to_user(userId, event)`

### 7.2 创建 `backend/a_用户与聊天/ws/emit.py`

- 暴露 5 类事件发送函数（**所有 Agent 必用**）：
  ```python
  def emit_agent_start(traceId, agentName, step, payload): ...
  def emit_agent_thinking(traceId, agentName, step, content): ...
  def emit_agent_result(traceId, agentName, step, content): ...
  def emit_agent_debate(traceId, agents, topic): ...
  def emit_agent_final(traceId, ok, summary): ...
  ```

### 7.3 创建 `backend/a_用户与聊天/ws/router.py`

- `WS /ws/{userId}` 端点
- 客户端连上时把 userId 存到 `manager`

### 7.4 创建 `backend/a_用户与聊天/ws/event_store.py`（断线重连用）

- 用 Redis 缓存最近 100 条事件
- 客户端重连时按 traceId 回放

**输出**：完整的 WebSocket 通道 + 5 类事件

**验证**：
- [ ] 前端连上 `/ws/{userId}` → 服务端推 `agent.start` → 前端收到
- [ ] 断线后重连 → 能回放最近事件
- [ ] **B / C / D 都能 `from backend.a_用户与聊天.ws.emit import emit_agent_xxx`**

**详细步骤**：[`workflows/08_WebSocket接入流程.md`](file:///d:/TZB/TZB-XH202630/backend/workflows/08_WebSocket接入流程.md)

**失败处理**：B / C / D 报 ImportError → 检查 `__init__.py` 是否 export
