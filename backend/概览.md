## 夺奖重点（**所有人必读，开工前先看**）

### 3 项硬指标（一票否决项）
| 指标 | 目标值 | 负责区 | 计算函数 |
| --- | --- | --- | --- |
| 专业知识谬误率（幻觉率） | **< 5%** | D（审核裁判 Agent）+ B（知识库切片） | `公共/metrics.py: calc_hallucination_rate` |
| 学习者画像-资源难度适配准确率 | **≥ 85%** | C（领域专家 Agent + 3 种形态资源） | `公共/metrics.py: calc_match_accuracy` |
| 核心知识点覆盖率 | **≥ 90%** | B（知识库切片 + 画像诊断） | `公共/metrics.py: calc_coverage` |

**任一项不达标 → 实用价值 30 分必扣 5-30 分**，A-05 端到端跑通 3 项指标才允许提交。

### 3 个核心 Agent（完整性 30 分核心）
- **学情诊断 Agent**（B-05）— 精准锚定强弱项
- **领域专家 Agent**（C-04）— 基于知识库生成 3 种形态资源
- **审核裁判 Agent**（D-06）— 与领域专家**辩论 + 交叉验证**

**协同编排由 D-03 负责**（分析-生成-校验-决策闭环），**所有 Agent 过程必须**通过 A-04 的 WebSocket 实时推送 5 类事件给前端可视化（用户体验 15 分核心）。

### 9-5 必交材料清单（缺一不可）
1. ✅ 源码（私有仓库需开放评审权限）
2. ✅ 部署说明
3. ✅ 单元测试用例（针对 Agent 协同逻辑 + 知识生成准确性）
4. ✅ **≥ 1 个垂直领域专业知识库切片**（B-06）
5. ✅ **≥ 3 组差异化学习者画像**（B-07，含完整输入输出示例）
6. ✅ **10 分钟以内演示视频**（D-08，3 套脱敏样例 + 协同可视化 + 动态迭代）
7. ✅ **PPT**（D-09，15-20 页）

## 关键约定：数据库由各区自管

- **每个区一个独立数据库**（`USER_CHAT_DB_URL` / `STUDENT_DATA_DB_URL` / `LEARNING_CONTENT_DB_URL` / `AI_INTEGRATION_DB_URL`），可选用不同的存储（PostgreSQL / MySQL / SQLite / 内存）
- 数据库连接 / ORM / 表结构全部在自己区目录内，**互不干涉**
- 跨区访问数据只能通过对方区暴露的模块级函数（A 暴露 `get_user_by_id`，B 暴露 `get_student_snapshot`，C 暴露 `save_ai_generated_*`），**禁止**直连对方数据库
- `公共/` 只放无状态的跨区工具（response / logger / errors / config 基础字段 / auth_middleware）

## 启动与协作流程

1. **A 先开工**：
   - 完成 S-01（公共基础工具）
   - 完成 A-00（用户与聊天 自有 DB）+ A-01（认证）+ S-02（auth_middleware）
   - 提交后通知 B/C/D，B/C/D 即可开工各自的 B-00 / C-00 / D-00
2. **B / C / D 并行**：各自先完成自己的 00 任务（自有数据层），再做 01+ 业务任务
3. **D 最后接入 AI**：在 A、B、C 已有接口之上，封装 3 个 AI provider，完成 `/api/ai-chat/*`、`ai-result` 等
4. **每日同步**：4 人每天 commit 前**只动自己目录**；`公共/` 修改需 4 人评审

## 3 个 AI 接入位置（成员 D）

| AI 名称 | 用途 | 路由 | D 目录中的文件 |
| --- | --- | --- | --- |
| AI 辅导 | 主对话答疑 | `/api/ai-chat/send` | `d_AI集成/chat/send.py` + `d_AI集成/providers/chat_ai.py` |
| AI 路径生成 | 生成学习路径 | `/api/learning-path/ai-result` | `d_AI集成/path/ai_result.py` + `d_AI集成/providers/path_ai.py` |

## Git 提交规范

- 一个成员一个分支：`feat/A-用户与聊天`、`feat/B-学情数据`、`feat/C-学习内容`、`feat/D-AI集成`（**目录已用 1/2/3/4 编号：`a_用户与聊天/`、`b_学情数据/`、`c_学习内容/`、`d_AI集成/`**）
