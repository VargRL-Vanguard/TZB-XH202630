# 4_AI集成/ — 成员 D：AI 集成（3 个 AI）

> 3 个 AI 的接入层，**最后开工**，依赖 A / B / C 的稳定接口。

## 负责接口

- AI 辅导对话：
  - `POST   /api/ai-chat/send`
  - `GET    /api/ai-chat/history`
  - `DELETE /api/ai-chat/history`
- AI 路径生成（**不**在 C 的目录里）：
  - `POST /api/learning-path/ai-result`
  - `GET  /api/learning-path/ai-result`
- AI 建议生成（**不**在 C 的目录里）：
  - `POST /api/suggestions/ai-result`
  - `GET  /api/suggestions/ai-result`

## 3 个 AI 适配

| AI | 用途 | 文件 |
| --- | --- | --- |
| ChatAI    | 主对话答疑 | `providers/chat_ai.py` |
| PathAI    | 学习路径生成 | `providers/path_ai.py` |
| SuggestAI | 学习建议生成 | `providers/suggest_ai.py` |

3 个 provider **必须**实现 `providers/base.py` 里的统一接口：

```python
class BaseAIProvider(Protocol):
    name: str
    async def invoke(self, prompt: str, *, context: dict, **kwargs) -> str: ...
```

切换 / 新增 AI 服务（接 3 个 AI 时）只改 `providers/` 目录，业务路由不动。3 个 AI 的 key / endpoint 由本区 `config.py` 读取。
