## 依赖 / 被依赖

- **依赖**：A 提供的 `userId` 鉴权中间件（位于 `公共/auth_middleware.py`）
- **被依赖**：D（AI集成）在拼装 prompt 时会调用本区的 `get_student_snapshot` / `get_recent_activities`

## 数据库归属

本区拥有独立的数据库（`STUDENT_DATA_DB_URL` 指向），A / C / D 任何代码**不可**直连本区数据库，只能调用本区暴露的模块级函数。

## 数据对外约定（供 D 使用）

为方便 D 拉数据，B 暴露以下**只读**聚合函数：

- `from backend.2_学情数据.student import get_student_snapshot`
- `get_student_snapshot(studentId) -> dict`  ← AI 路径 / 建议生成时一次性拿到所需画像
- `from backend.2_学情数据.activity import get_recent_activities`
- `get_recent_activities(studentId, days=7) -> list`

字段与 `api-doc.js` 中 `/api/student/*`、`/api/activity/*` 返回结构保持一致。
