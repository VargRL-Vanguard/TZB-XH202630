## 遇到的问题

> 实施过程中遇到的问题记录在这里，方便后续 B/C/D 避坑。

### 2026-08-11

#### 问题 1：依赖在 PowerShell 终端粘贴多行被逐行当作命令执行
- **现象**：直接把 `fastapi==0.115.0\nuvicorn...` 粘贴到 PowerShell，每行被当 cmdlet 执行，报 `无法识别`。
- **解决方案**：先创建 `backend/requirements.txt` 文件，再运行 `pip install -r backend\requirements.txt`。

#### 问题 2：`ModuleNotFoundError: No module named 'backend'`
- **现象**：第一次 `python -c "from backend.公共 import ..."` 报同样错误。
- **解决方案（部分）**：在 `backend/` 目录下创建空的 `__init__.py`，使 `backend` 成为 Python 包。

#### 问题 3：`SyntaxWarning: invalid escape sequence '\['`
- **现象**：`metrics.py` 里 `_PUNCT_RE = re.compile(r"[\s,...\[]...")`，字符类里 `\[` 被当作无效转义。
- **解决方案**：在字符类里 `\[` 是合法转义，警告来自前后的 `"` 和 `""''` 部分。最终用 `r"[\s，。！？、；：\"'《》（）()\[\]【】\-—,.!?;:]+"` 全部转义为 `\\` 或 `\"`。

#### 问题 4：`pytest` 仍然报 `No module named 'backend'`
- **现象**：`from backend.公共 import ...` 直接运行时 OK，但 `pytest backend\公共\tests\` 仍然找不到 `backend` 包。
- **原因**：pytest 默认不会把项目根目录加进 `sys.path`，它只把 `conftest.py` 所在目录加进去。测试代码用的是**绝对导入** `from backend.公共.xxx`，需要 `D:\TZB\TZB-XH202630` 在 `sys.path` 里。
- **解决方案**：在项目根目录创建 `pyproject.toml`，配置 `pythonpath = ["."]`：

  ```toml
  [tool.pytest.ini_options]
  pythonpath = ["."]
  testpaths = ["backend"]
  asyncio_mode = "auto"
  asyncio_default_fixture_loop_scope = "function"
  ```

#### 问题 5：`backend/公共/__init__.py` 循环引用
- **现象**：`from backend.公共 import response, logger, errors, config, metrics` 写在 `backend/公共/__init__.py` 内部，形成自引用。
- **影响**：Python 容忍（子模块先于 __init__ 完成体加载），所以 `python -c` import 不会报错；但 pytest 收集时这种写法不规范。
- **解决方案**：保留子模块导入（必须，否则 `from backend.公共 import response` 不工作），但简化 `__init__.py` 内容，并加 `# noqa: F401` 防止 flake8 报错；删掉冗余的 `__all__`（不必要，且里面的快捷符号 `ok / fail / BizError / ...` 没真正 re-export，会误导）。

## 给 B/C/D 的避坑指南

1. **测试文件必须用绝对导入** `from backend.公共.xxx import yyy`，不要用 `from ..公共 import` 相对导入。
2. **项目根目录必须有 `pyproject.toml`**（已加），否则 pytest 收集不到 `backend` 包。
3. **正则里的 `[ ] \ -`** 必须转义成 `\[ \] \-`；raw string + 双反斜杠 `\\` 仍然会触发警告，**正确做法**是 `r"[\[\]\\-]"`（raw string 内部 `\[` 就足够）。
4. **不要在 `__init__.py` 里 `from <自身包> import ...`**，会形成循环；只 `import` 不 `from` 即可。
5. **新成员跑测试前先确认** `pip install -r backend\requirements.txt` 已执行；项目根目录在 `D:\TZB\TZB-XH202630`。
