## ADR 命名规范

- 文件名：`NNNN-<任务或主题>.md`
- NNNN = 4 位序号（0001、0002、...）
- 状态：📝 草案 / ✅ 已采纳 / ❌ 已废弃 / 🔄 替代 NNNN

---

## ADR 模板

每份 ADR 必须包含 5 个部分：

```markdown
# ADR-NNNN：标题

**状态**：✅ 已采纳
**日期**：YYYY-MM-DD
**决策者**：A（成员 1）

## 背景
为什么要做这个决策？问题是什么？

## 备选方案
- 方案 A：...
- 方案 B：...

## 决策
选哪个？为什么？

## 后果
- 正面：...
- 负面：...
- 后续影响：...

## 参考
相关文档、链接、issue
```

---

## 维护说明

- **任何成员**都可以新增 ADR
- ADR 一旦写就**不修改**（错了就标 ❌ 废弃 + 新建一个）
- 重大选型（框架 / 数据库 / AI 模型）必须先有 ADR
