## 3 大 Agent 之领域专家 Agent（C-04 ⭐）

> **挑战杯 3 个核心 Agent 之一**（其他 2 个在 B-05 / D-06）。

**职责**：接 B 的诊断结果 → 调 B 的 `list_kb_chunks_by_kp` 检索知识库 → **强制**基于检索内容生成 → 自动调 A 的 `calc_coverage` + `calc_hallucination_rate` 自检。
**入口**：`backend.3_学习内容.agents.generate_resource(studentId, diagnosis, resource_type)`
**支持 3 种形态**：`customized_resource` / `practice_guide` / `tiered_quiz`
**事件**：通过 A-04 `ws.emit(agentName="领域专家Agent", ...)` 实时推送。

## 3 项硬指标责任

| 指标 | C 的贡献 |
| --- | --- |
| 适配准确率 | **C-04 领域专家 Agent** 必须根据 `learnerProfile.weakKPs` 精准匹配难度，目标 ≥ 0.85 |
| 覆盖率 | C-04 生成时调 A 的 `calc_coverage`，< 0.90 时自动重试 |
| 幻觉率 | C-04 生成时调 A 的 `calc_hallucination_rate`，> 0.05 时自动重试 |
