# 公共/ — 公共基础设施（无数据层）

> 任何成员**可引用**、但**不得修改**。所有修改需 4 人评审后由成员 A 落地。

## 关键约定：数据库不在 公共/

`公共/` **不**提供 `db.py`。每个业务区**自管**自己的数据层（自己的 `db.py` / `config.py` / `models/`），原因：

- 数据库是各区私有数据，互不依赖，互不干涉
- A 改 `db.py` 不会影响 B/C/D；B 改库不会影响 A
- 各区可选用不同的存储方案（PostgreSQL / MySQL / SQLite / 内存 Mock）互不约束

## 谁来初始化

由 **成员 A** 在第一阶段创建并提交，之后由 A 维护。

## 文件清单

```
公共/
├── 概览.md
├── config.py        # 基础配置：PORT / LOG_LEVEL / ENV / JWT_SECRET（**不含** DB_URL）
├── response.py      # 统一响应封装：{ code, message, data }
├── auth_middleware.py  # 解析 token → userId，供 B/C/D 路由使用
├── logger.py        # 日志封装
└── errors.py        # 自定义异常与错误码
```

## 使用约定

- B / C / D 通过 `from backend.公共.xxx import ...` 引用
- 不在本目录写业务逻辑；只放"4 个区都会用到"且**无状态**的东西
- 任何扩展（缓存、限流、消息队列客户端等）先在本目录评审通过再使用
