## 6. 切片规则（AI 必须遵守）

1. **切片粒度**：200-500 字 / chunk
2. **语义完整**：每片必须有完整意思，不要从段落中间劈开
3. **kp_tags 必填**：每个 chunk 至少 1 个 kp_tag
4. **来源必填**：`source` 字段指向原始资料的具体章节
5. **难度必填**：`difficulty` 1-5，对应学生的推荐难度

---

## 7. eval_coverage.py 模板

```python
# backend/b_学情数据/knowledge_base/eval_coverage.py
"""
运行后输出：
- 总 kp 数
- 有 chunk 引用的 kp 数
- 覆盖率 = 有引用 kp / 总 kp
- 未覆盖的 kp 列表（必须 < 10%）
"""
import json
from pathlib import Path

def main():
    kp_taxonomy = json.loads(Path("kp_taxonomy.json").read_text())
    chunks_dir = Path("chunks")
    
    total_kps = len(kp_taxonomy["kps"])
    covered_kps = set()
    
    for chunk_file in chunks_dir.glob("*.json"):
        chunk = json.loads(chunk_file.read_text())
        for kp in chunk.get("kp_tags", []):
            covered_kps.add(kp)
    
    coverage = len(covered_kps) / total_kps
    
    print(f"总 kp 数: {total_kps}")
    print(f"已覆盖 kp 数: {len(covered_kps)}")
    print(f"覆盖率: {coverage:.2%}")
    
    uncovered = [kp["id"] for kp in kp_taxonomy["kps"] 
                 if kp["id"] not in covered_kps]
    print(f"未覆盖 kp: {uncovered}")
    
    if coverage < 0.90:
        raise ValueError(f"覆盖率 {coverage:.2%} < 90%，需补充切片")

if __name__ == "__main__":
    main()
```
