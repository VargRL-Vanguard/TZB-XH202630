## C-04 领域专家 Agent（**3 大 Agent 之一**）
```python
def generate_resource(studentId, diagnosis_result, resource_type) -> Resource:
    # 1. 拿 diagnosis_result 里的 weakKPs / knowledgeGaps
    # 2. 调 B 的 list_kb_chunks_by_kp(kp) 检索知识库（每个 kp 至少 3 个 chunk）
    # 3. 调 D 的 ai_service（或直接 provider）+ 拼 prompt
    #    - prompt 必须**强制**写："你只能基于以下参考资料回答，不能自由发挥"
    #    - 把检索到的 chunk 作为 context 拼入
    # 4. 调 A 的 calc_coverage(content, kp_ids) — < 0.90 自动重试 1 次
    # 5. 调 A 的 calc_hallucination_rate(content, ground_truth_chunks) — > 0.05 自动重试 1 次
    # 6. 写 resource 表 + 写 resource_version 表
    # 7. 通过 A-04 的 ws.emit(agentName="领域专家Agent", ...) 推过程
    # 8. 返回 resource_id
```

**3 种形态资源**：
| type | 含义 | 必含字段 |
| --- | --- | --- |
| `customized_resource` | 定制化资源（讲义） | 概念/案例/小结 + kp_coverage |
| `practice_guide` | 实操指南 | 前置条件/工具/步骤/排错 |
| `tiered_quiz` | 分阶测试题 | 3-5 题 + difficulty 1-5 + 答案 + 解析 |
