# 🎬 演示视频脚本提示词（D-09）

> **使用对象**：D 区（AI 集成）AI 协作者
> **关联任务**：[D-09 演示视频与答辩材料](../../任务清单_d_AI集成.md#d-09)
> **重要性**：⭐⭐⭐ **挑战杯必交材料 + 评委第一印象**

---

## 1. 任务目标

制作 **10 分钟演示视频**，展示系统的"3 大 Agent 协同 + 实时可视化"完整流程。

**这是评委唯一会"看"的东西，必须有故事性 + 技术感。**

---

## 2. 必达指标

| 指标 | 目标 |
| --- | --- |
| 时长 | **≤ 10 分钟**（硬性要求） |
| 完整性 | 必须展示 1 次完整编排（学生提问 → 资源生成） |
| 可视化 | 3 大 Agent 协同过程**实时可见** |
| 3 项硬指标 | 视频结尾展示 `docs/quality_reports/` 报告 |
| 故事性 | 用**画像 3（企业转岗）**作为主角 |

---

## 3. 时间分配（10 分钟）

| 段 | 时长 | 内容 |
| --- | --- | --- |
| 1. 开场 | 0:00-0:30 | 项目背景 + 痛点（30 秒） |
| 2. 架构总览 | 0:30-1:30 | 3 大 Agent + 协同流程图（1 分钟） |
| 3. 演示场景 | 1:30-7:00 | **重点！**画像 3 完整流程（5.5 分钟） |
| 4. 3 项硬指标 | 7:00-8:30 | 展示 quality_report 表格（1.5 分钟） |
| 5. 技术创新 | 8:30-9:30 | 动态迭代 / 多 Agent 辩论亮点（1 分钟） |
| 6. 结尾 | 9:30-10:00 | 总结 + 致谢（30 秒） |

---

## 4. 演示场景详细脚本（5.5 分钟，**最重要**）

### 4.1 场景设定（0:00-0:30）

> "今天我们要展示的是赵刚的案例：他是一名有 5 年经验的软件工程师，最近转岗到工业机器人调试领域。他的强项是编程和实操，但工业机器人理论（运动学、PLC）是他的弱项。"

### 4.2 前端发起请求（0:30-1:00）

- 打开前端页面
- 选择"画像 3：赵刚"
- 点击"生成定制讲解"
- 弹出 WebSocket 实时协同流程面板

### 4.3 B-05 学情诊断（1:00-2:00）

- 屏幕特写：WebSocket 事件流 `agent.thinking (B-05)`
- 旁白："学情诊断 Agent 正在分析赵刚的 80 条历史答题记录..."
- 显示诊断结果：weakKPs = ["kp_010: PLC基础", "kp_020: 运动学"]，推荐难度 3
- 推 `agent.result` 事件

### 4.4 C-04 领域专家生成（2:00-4:00）

- 屏幕特写：WebSocket 事件流 `agent.thinking (C-04)`
- 旁白："领域专家 Agent 正在调用知识库..."
- 显示检索到的 5 个 chunks（带 kp_tags）
- 显示生成的定制讲解 Markdown（特写关键段落）
- 推 `agent.result` 事件

### 4.5 D-06 审核裁判（4:00-5:00）

- 屏幕特写：WebSocket 事件流 `agent.audit`
- 旁白："审核裁判 Agent 正在校验..."
- 显示评分：hallucinationRate=0.02, coverage=0.92, **score=0.95**（pass）
- 推 `agent.final` 事件

### 4.6 资源展示（5:00-5:30）

- 屏幕特写：生成的定制讲解页面
- 旁白："系统为赵刚生成了 PLC 基础和运动学的定制讲解..."

---

## 5. 3 项硬指标展示（1.5 分钟）

切到 `docs/quality_reports/quality_report_*.md`：

> "系统经过 3 组测试画像的严格验证，3 项硬指标全部达标："

| 指标 | 实际 | 目标 |
| --- | --- | --- |
| 幻觉率 | 3.2% | < 5% ✅ |
| 画像-难度适配准确率 | 92% | ≥ 85% ✅ |
| 核心知识点覆盖率 | 91% | ≥ 90% ✅ |

---

## 6. 技术创新展示（1 分钟，**夺奖加分项**）

### 6.1 动态迭代

- 展示一个学生答题"正确率 < 0.6"的场景
- 系统自动生成"降维解释"资源
- 旁白："系统支持根据学生答题反馈动态调整资源难度"

### 6.2 多 Agent 辩论

- 展示一个 score < 0.70 的场景
- 触发 `agent.debate` 事件
- 旁白："当审核不通过时，系统会触发多 Agent 辩论，确保输出质量"

## 9. 验收标准

- ✅ 视频时长 ≤ 10 分钟
- ✅ 包含 1 次完整编排流程（学生 → 资源）
- ✅ 3 项硬指标报告展示清晰
- ✅ 3 大 Agent 协同过程可视化
- ✅ 故事性完整（用画像 3 转岗作为主线）
- ✅ PPT 张数 ≤ 15 页
- ✅ 9-5 前已完成初剪 + 内部审核

---

## 10. 禁止事项

- ❌ 不要让视频超过 10 分钟（硬性要求）
- ❌ 不要在没有可视化的情况下讲 Agent 协同
- ❌ 不要漏掉 3 项硬指标报告
- ❌ 不要用 3 个无差异的画像做演示（必须用画像 3）
- ❌ 不要在 9-5 最后一天才录视频（必须预留剪辑时间）
