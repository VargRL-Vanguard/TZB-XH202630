# 👥 测试画像专项提示词（B-07）

> **使用对象**：B 区（学情数据）AI 协作者
> **关联任务**：[B-07 测试画像](../../任务清单_2_学情数据.md#b-07)
> **重要性**：⭐⭐⭐ **用于"画像-难度适配准确率 ≥ 85%"指标计算 + 演示视频主角**

---

## 1. 任务目标

生成 **3 组背景差异显著的测试学生画像**，用于：
1. 计算"画像-难度适配准确率"（3 项硬指标之一）
2. 演示视频中作为"展示学生"（详见 31 号提示词）
3. A-05 端到端验收脚本的输入数据

---

## 2. 必达指标

| 指标 | 目标 |
| --- | --- |
| 画像数量 | **3 组**（必须 3 组） |
| 背景差异 | 必须显著（学历 / 经验 / 领域） |
| 数据格式 | JSON，可直接被 A-05 quality_check 加载 |
| 必含字段 | 见下方 schema |

---

## 3. 画像 schema

```json
{
  "student_id": "test_001",
  "name": "张三",
  "background": {
    "education": "本科应届",
    "major": "机械工程",
    "experience_years": 0,
    "domain": "智能制造"
  },
  "history": {
    "answer_records": [
      {
        "kp_id": "kp_001",
        "question_id": "q_001",
        "correct": true,
        "difficulty": 2,

      }
    ],
    "total_questions": 50,

```

## 4. 3 组画像的具体要求

  "background": {
    "education": "本科应届",

    "weakKPs": ["kp_020"],

---

## 6. 验收标准

- ✅ 3 个 JSON 文件齐全
- ✅ 每个画像背景差异显著（学历 / 经验 / 领域至少有 1 项不同）
- ✅ `expected.weakKPs` 全部在 `kp_taxonomy.json` 存在
- ✅ A-05 quality_check 能直接加载并跑通
- ✅ 演示视频中选用画像 3（最有故事性的转岗场景）

---

## 7. 禁止事项

- ❌ 不要 3 组画像都长得差不多（背景必须差异显著）
- ❌ 不要让 expected.weakKPs 引用不存在的 kp_id
- ❌ 不要漏掉画像 3 的"跨领域"特征（最有演示价值）
