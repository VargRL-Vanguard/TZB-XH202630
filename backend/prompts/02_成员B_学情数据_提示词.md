# ⭐ 夺奖专项任务的硬要求

## B-05 学情诊断 Agent
```python
def diagnose(studentId) -> DiagnosisResult:
    # 1. 调 A 的 get_learner_profile(studentId) 拿画像
    # 2. 调自己的 get_student_snapshot(studentId) 拿完整数据
    # 3. 调自己的 get_recent_activities(studentId, days=30) 拿历史
    # 4. 拼 prompt → 调 D 的 ai_service（或直接 provider）
    # 5. 用 A 的 calc_match_accuracy 自检（与画像自洽）
    # 6. 通过 A-04 的 ws.emit(agentName="学情诊断Agent", ...) 推过程
    # 7. 落 diagnosis_record 表
    # 8. confidence < 0.6 → 抛 QualityError
```

## B-06 知识库切片（**9-5 必交**）
- 至少 1 个垂直领域（推荐：智能制造 / 工业机器人 / PLC / 工业互联网）
- **核心知识点数 ≥ 30**（`kp_taxonomy.json`）
- **切片数 ≥ 200**（每个 chunk 200-500 字）
- 每个 chunk 含 `kp_tags`（JSON 数组）
- `eval_coverage.py` 跑通后**核心知识点覆盖率 ≥ 0.90**
- `kb/source/README.md` 含：领域、版本、来源、版权、chunk 数、kp 数、覆盖范围
- **数据来源合规**：公开教材 / 国标 / 团队原创均可；**禁用**未授权商业资料

## B-07 测试画像（**9-5 必交**）
- **3 组** JSON，背景差异显著：
  - 画像 1：本科应届生，理论分 80+，期望 strong 偏多
  - 画像 2：高职在读生，理论分 60，weak 偏多
  - 画像 3：企业转岗人员，技能实战强，理论偏弱，**跨领域背景**
- 每组配 1 份 `expected_*.json`（**人工标注**的预期弱知识 + severity + reason）
- `README.md` 含差异点对比表 + ≥ 200 字预期诊断说明

# ⚠️ 关键红线
