## 快速使用方式

### 方式 1：复制粘贴发给你的 AI
1. 打开 `00_项目全局启动提示词.md` → **整段复制** → 粘贴给你的 AI
2. AI 读完会回复"已读完 3 项硬指标红线 + 多 Agent 协作模式"
3. 然后打开 `0X_成员X_xxx_提示词.md` → 整段复制 → 粘贴
4. 接着打开当前任务的专项提示词 → 整段复制 → 粘贴
5. 最后告诉 AI："请认领并完成 `<区>-<编号>`（标题）"

### 方式 2：让 AI 自己检索
把以下 prompt 发给 AI，让它**自己来读**：
```
请按以下顺序完整阅读本项目后端的提示词库（**每一份都要读**）：
1. backend/prompts/00_项目全局启动提示词.md
2. backend/prompts/README.md（拿到索引）
3. backend/prompts/0X_成员X_xxx_提示词.md（找到我所在的区）
4. backend/prompts/<专项提示词>.md（按当前任务选）
5. backend/任务清单_N_xxx.md（我所在的区）
6. backend/概览.md
7. backend/协作协议.md
8. backend/AI协作指南.md
9. backend/<我所在区>/概览.md
10. 项目根目录的 api-doc.js

读完后请回答：
- 你是哪个成员？
- 你负责的目录是什么？
- 你当前任务的 ID 和验收标准是什么？
- 3 项硬指标红线是什么？
- 你的工作范围边界是什么（不能碰哪些文件）？
```

## 维护说明

- **任何成员**都可以新增 / 优化自己区的提示词
- **修改全局入口 `00_xxx.md`** 需 4 人评审
- **新增专项提示词** 命名规范：`NN_<主题>_提示词.md`，NN 按主题分类（10=Agent / 20=知识库 / 30=验收 / 40+=自定义）
- 所有提示词**不**写到代码里（**不**放进任何 `*.py` / `*.js`），仅作为 Markdown 文档供 AI 检索
