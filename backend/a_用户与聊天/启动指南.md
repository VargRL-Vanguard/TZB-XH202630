### 3.3 用 Python 测试 A-04 WebSocket
```python
import asyncio
import websockets
import json

async def test():
    token = "<上面登录拿到的 token>"
    uri = f"ws://localhost:8000/ws?token={token}"
    async with websockets.connect(uri) as ws:
        # 1. 收 connected
        print(await ws.recv())

        # 2. 订阅
        await ws.send(json.dumps({"type": "subscribe", "channel": "agent:test"}))

        # 3. 等待推送
        msg = await ws.recv()
        print(msg)

asyncio.run(test())
```

## 4. 常见问题

### Q1：`ModuleNotFoundError: No module named 'backend'`
**A**：在项目根目录（`D:\TZB\TZB-XH202630`）启动，不要在 backend 目录里启动。

### Q2：`pymysql.err.OperationalError: (1045, ...)`
**A**：`.env` 里的 `USER_CHAT_DB_URL` 密码错。检查 `.env` 文件，用纯 ASCII 字符。

### Q3：WebSocket 测试报 `'Event loop is closed'`
**A**：每个测试用新 event loop，但 `NullPool` 已经规避，**不要**改回默认连接池。

### Q4：bcrypt 报 `__about__` warning
**A**：passlib 1.7.4 + bcrypt 4.x 的兼容性问题，不影响功能，可以忽略。
