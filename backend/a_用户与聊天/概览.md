# a_用户与聊天/ — 成员 A：用户与基础聊天（**挑战杯多 Agent 地基**）

> 4 人中的**地基**。A 需先完成本区，B / C / D 才能基于 `userId / token` 开工。
> **本项目参赛 XH-202630 挑战杯，目标擂主**。A 负责 3 项硬指标计算器 + 学习者画像 + WebSocket Agent 协同事件通道 + A-05 端到端验收。

## 负责接口

- 用户认证：`/api/auth/login`、`/api/auth/register`、`/api/auth/logout`
- 用户信息：`/api/user/info`、`/api/user/profile`（**夺奖新增**，含学习者画像）
- 聊天：`/api/chat/history`、`/api/chat/send`、`/api/chat/list`、`/api/chat/read`
- 实时通道：`/ws`（**5 类 Agent 协同事件：start / thinking / result / debate / final**）

> 原 `api-doc.js` 中 `/api/chat` 的用户信息接口归本区。

## 3 项硬指标责任

A 维护 `公共/metrics.py`，提供 3 个纯函数（B/C/D **直接调**，禁止重写）：
- `calc_hallucination_rate(generated, ground_truth) -> float` — 目标 < 0.05
- `calc_match_accuracy(profile, resource_difficulty) -> float` — 目标 ≥ 0.85
- `calc_coverage(generated, required_kps) -> float` — 目标 ≥ 0.90

A-05 `公共/quality_check.py` 端到端跑 3 项指标，是 9-5 提交前的**最后一道关**。
