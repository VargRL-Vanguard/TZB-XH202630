## 二、题目名称
领域知识个性化生成与多智能体协同决策系统研究

## 三、题目介绍

### 1. 题目背景
- 国家推进"新质生产力"，对劳动者素质和技能要求提高
- 教育从"知识本位"向"能力本位"转型
- 大模型爆发，为教育内容按需生成提供可能
- 痛点：大模型在 AI 等前沿领域生成内容时存在"幻觉"问题
- 矛盾：放开限制去迎合学情 → 失去专业准确性；严格限制 → 失去个性化
- 目标：把大模型从"通用聊天工具"转化为"懂专业、精技能、能落地"的新型教育基础设施

### 2. 目标介绍
提出"多智能体协同决策"技术思路，构建"多 Agent 协同架构"：
- **学情诊断 Agent**：精准锚定学习者的理论强项与技能盲区
- **领域专家 Agent**：依托专业知识库确保内容生成的绝对专业与零幻觉
- **审核裁判 Agent**：进行交叉验证
- 多角色相互博弈与协同决策
- 系统能力：低成本动态生成高度个性化领域资源 + 知识高保真高可控

### 3. 选题意义
**技术意义**：
- 突破垂直领域大模型落地瓶颈
- 多智能体协同可实现垂直领域高保真知识生成
- 为复杂业务逻辑下的大模型调度提供普适性方法
- 解决 AI 在专业内容生成"不可控、不专业"的痛点

**经济社会效益**：
- 精准解析学习者"既有理论底盘"，破解个性化资源生成成本高
- 双重价值：
  1. 为产业从业人员和学习者提供定制化技能训练，加速理论向工程能力转化
  2. 为院校及企业培训部门提供敏捷资源生产引擎，极低边际成本替代传统高耗能实习开发

## 五、答题要求

### 1. 作品要求

设计并开发一套面向垂直领域技能培训的领域知识个性化生成与多智能体协同决策系统。

**(1) 场景覆盖**：
- 不限于：智能制造、工业互联网、特定软件开发、人工智能等垂直领域
- 典型技能培训场景
- 明确体现对不同背景学习者的适配能力

**(2) 多智能体协同与生成机制**：
- 至少构建 **3 个及以上** 具有明确职责分工的智能体
  - 学情诊断 Agent
  - 领域知识生成 Agent
  - 内容审核与纠偏 Agent
- 实现"分析-生成-校验-决策"的协同闭环
- 整合学习者先验知识画像（学历背景、理论测试结果）+ 领域专业知识库
- 动态生成至少 3 种形态的个性化学习资源：定制化资源、实操指南、分阶测试题

**(3) 智能决策与反馈**：
- ① 支持生成可视化的个人学情与资源匹配度报告：
  - 知识盲区定位
  - 资源难度匹配曲线
  - 学习路径规划图
  - 帮助培训管理者或学习者直观决策
- ② 提供基于学习交互反馈的动态迭代机制：
  - 如根据答题正确率
  - 多智能体协同决策是否对知识点进行"降维解释"或生成"进阶挑战任务"

**(4) 创新性要求**：
- ① 探索多智能体间的创新协同架构
  - 引入"辩论与交叉验证"机制
  - 消除大模型在专业领域的"幻觉"
  - 实现高保真知识溯源与约束生成
- ② 探索大模型驱动下的动态追问与启发式交互导学技术
  - 打破静态资源的单向输入局限

**(5) 数据合规性与伦理规范**：
- 若使用真实培训、测试或学情数据
- 需符合法律法规及隐私保护要求
- 用户画像数据、交互记录的脱敏处理、合规使用

**(6) 其他场景和行业延伸（可选）**：
- 向企业高标准化内训、转岗培训等高要求场景拓展
- 探索在更广泛终身教育体系中的社会化普惠应用价值

### 2. 作品提交形式

**(1) 材料文档**：
- 作品设计实现方案
- 作品介绍
- **10 分钟以内的系统演示视频**（清晰展示）：
  - 差异化学习者学情画像输入
  - 多智能体协同调度与交互过程的可视化
  - 最终个性化领域知识资源生成的完整闭环

**(2) 软件模块**：
- 作品的源代码（可开源链接，私有仓库需开放评审权限）
- 可执行程序（如有）
- 部署说明
- **单元测试用例**（针对多智能体协同调度逻辑与领域知识生成准确性等核心模块）

**(3) **测试数据**：
- 至少 1 个垂直领域的专业知识库切片（用于检索的领域文档或实操数据）
- 不少于 2 组差异化的学习者初始学情数据源
  - 输入画像特征
  - 多智能体协同决策中间数据
  - 最终生成的个性化学习资源
  - 完整的输入输出示例

## 六、作品评选标准（百分制）

| 项 | 分值 |
| --- | --- |
| 1. 作品完整性 | 30 分 |
| 2. 技术创新性 | 25 分 |
| 3. 用户体验 | 15 分 |
| 4. 实用价值 | 30 分 |
| 合计 | 100 分 |

### 1. 作品完整性（30 分）
研发并完成 **"学情画像构建 → 多智能体协同调度（诊断/生成/审核）→ 领域知识个性化生成 → 交互反馈 → 动态决策更新"** 全流程闭环系统。多智能体角色分工明确且协作顺畅（学情 Agent、生成 Agent、审核 Agent 等），基础功能无缺失，系统能正常部署运行 → 得 30 分。

扣分区间：
- 未完成全流程闭环、核心功能缺失（多智能体协同调度或个性化生成机制缺失）→ 扣 5-15 分
- 未完成全流程闭环，但核心功能基本齐全，仅 Agent 间通信不畅、流程衔接卡顿或次要功能缺失 → 扣 5-15 分
- 未完成全流程闭环，且核心功能缺失（退化为单模型直接生成、无协同机制）、系统无法正常部署运行 → 扣 15-30 分

### 2. 技术创新性（25 分）
创新性应用大模型、多智能体等技术，突破传统"千人一面"的静态资源分发模式。核心技术方案（如基于多 Agent "**交叉验证与辩论**"机制解决垂直领域知识生成的"幻觉"问题）具备突破性与可行性，技术应用效果显著，能实现高保真领域知识的按需生成与科学定标，幻觉防控与知识溯源方案完善 → 得 25 分。

扣分区间：
- 有一定技术创新，应用大模型及多智能体相关技术，但未突破传统模式，核心技术方案无明显突破性，幻觉防控与合规方案基本完善 → 扣 5-10 分
- 技术创新不足，仅简单堆叠 API 或常规应用相关技术，未解决"幻觉"与"不可控"等核心问题 → 扣 10-15 分
- 无任何技术创新，未应用指定相关技术，核心技术方案缺失，生成内容存在严重专业知识谬误且无防控措施 → 扣 15-25 分

### 3. 用户体验（15 分）
界面简洁友好、操作流程便捷，多智能体协同调度过程与决策逻辑**可视化交互流畅**；生成的个性化学习资源（定制讲义、实操指南、分阶题目等）排版规范、展示清晰；交互导学体验自然 → 得 15 分。

扣分区间：
- 界面基本简洁，操作流程基本便捷，多智能体状态可视化基本流畅，资源展示基本清晰，少量操作繁琐或排版不美观 → 扣 3-5 分
- 界面不够简洁，操作流程繁琐，智能体调度过程无可视化或存在卡顿，资源结构混乱、不易阅读 → 扣 5-10 分
- 界面混乱、操作复杂，无法正常完成人机交互操作，系统处于黑盒状态，资源无法识别或存在大量排版错误 → 扣 10-15 分

### 4. 实用价值（30 分）
提供完整测试方案（含至少 1 个垂直领域的专业知识库，及 **≥3 组不同背景学习者画像**的测试用例）。生成的领域知识精准贴合行业实际规范与岗位需求，**三项准确率指标**：

| 指标 | 目标 |
| --- | --- |
| 专业知识谬误率（幻觉率） | **<5%** |
| 学习者画像-资源难度适配准确率 | **≥85%** |
| 核心知识点覆盖率 | **≥90%** |

能有效解决个性化培训痛点，且技术方案具备良好的领域泛化与可迁移能力 → 得 30 分。

扣分区间：
- 测试方案完整，1 项未达标（处于 75%-目标值之间），可迁移性一般 → 扣 5-10 分
- 测试方案不完整（用例不足 50 组或缺乏真实领域数据），2 项及以上未达标（60%-75%），可迁移性较差 → 扣 10-20 分
- 无系统化测试方案，存在违背行业常识的错误，三项指标均未达标（<60%），技术方案无迁移性 → 扣 20-30 分
