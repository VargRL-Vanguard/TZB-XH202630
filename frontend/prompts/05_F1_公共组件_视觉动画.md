## 任务清单：组件规格（照此实现，规格已定死）

### v1（8-21 前必须交付）

- [ ] **Skeleton.vue** 骨架屏：props `rows`(行数)、`variant`('card'|'text'|'chart')；呼吸动画 1.5s 循环；结构模拟真实内容布局
- [ ] **EmptyState.vue** 空态：props `icon`、`text`、`actionText`、`@action`；插画 + 引导文案 + 行动按钮
- [ ] **ErrorState.vue** 错误态：插画 + 一句话原因 + 重试按钮；**绝不显示堆栈/code 原文**
- [ ] **NetBanner.vue** 断网横幅：固定顶部黄色（警告色 `#F59E0B` 系）横幅"实时连接已断开，正在重连…"；由 WS store 断线状态驱动，恢复自动消失
- [ ] **MetricCard.vue** 指标卡：props `label`、`value`、`unit`、`trend`('up'|'down'|null)；数字 `font-variant-numeric: tabular-nums`；进视口滚动增长动画 800ms ease-out（0→目标值）
- [ ] **DifficultyBadge.vue** 难度徽章：props `level`(1-5)、`expected`(可选期望值)；颜色梯度绿→红；expected 传入时显示一致性标识（一致 ✅ / 偏高 ↑ / 偏低 ↓）
- [ ] **AgentCard.vue** 大屏 Agent 卡片：props `name`、`themeColor`、`icon`、`state`；状态机 `idle/running/done/debating/finished`——running 转圈呼吸灯、done ✅、debating ⚡ 边框；内部留 slot 给思考气泡区（D 会往里塞打字机内容）
- [ ] `components/README.md`：每个组件一段用法示例代码

### v2（8-25 前随页面落地）

- [ ] 全局 CSS 变量：主 `#4F6EF7` / 辅 `#7C5CFC` / 成功 `#22C55E` / 警告 `#F59E0B` / 危险 `#EF4444` / 大屏底 `#0B1020` / 页面底 `#F7F8FC` / 文字 `#1F2937` `#6B7280`
- [ ] 字体栈 `"PingFang SC", "Microsoft YaHei", sans-serif`；间距 8px 基数（8/16/24/32）；卡片圆角 8-12px，阴影 `0 2px 8px rgba(0,0,0,0.06)`（浅色页）
- [ ] 动画 token 统一：状态切换 200-300ms ease-out、页面切换 ≤200ms 淡入、`prefers-reduced-motion` 全局降级
- [ ] 逐页检查（配合各页负责人）：路由中文 `<title>` + favicon、tabular-nums、4 态交互
