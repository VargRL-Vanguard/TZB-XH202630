# 13 PR 提交前自检（每次 push 前跑一遍）

> 用法：commit 之前，把「自检提示词」+ 你这次改动的文件列表粘给 AI，零 error 才许 push。这个流程 3 分钟，省的是队长验收打回的半小时。

## 复制即用 · 自检提示词

```text
你是代码评审员。我刚完成一次前端改动，准备提交 PR。项目根 d:\TZB\TZB-XH202630，请按以下顺序检查我列出的文件：

1. 读 frontend/prompts/13_PR提交前自检.md 的「检查清单」，逐条对照我的代码
2. 读 frontend/prompts/08_接口契约速查表_字段级.md，核对我这次触碰到的所有接口调用/mock 数据字段名是否与契约一字不差
3. 输出报告：
   - ❌ 阻断项（必须改完才能提交）：给出文件+行号+改法
   - ⚠️ 建议项（可留到下个 PR）
   - ✅ 通过项（只列条目名）
4. 最后生成符合规范的 commit message（feat/fix/refactor + 中文描述）和 PR 描述（含自查结论 + 截图占位提醒）

我本次改动的文件：（列出文件路径）
```

## 检查清单（AI 逐条对照，人也要扫一眼）

### 功能与契约
- [ ] 涉及的接口路径/请求字段/响应字段与 08 号文档一字不差（含大小写）
- [ ] mock 数据放 `src/mock/fixtures/`，没有散落在组件里写死
- [ ] WS 事件 type 判定齐全，未知 type 有兜底不报错

### 安全（红线，违者打回）
- [ ] 无 v-html 直插 AI/用户内容；必须经 DOMPurify
- [ ] token 没出现在 URL / console.log / 组件裸 localStorage
- [ ] 用户输入渲染前已转义

### 边界 4 态（数据页面）
- [ ] 加载骨架屏（无 spinner 空转超 3s）
- [ ] 错误态有重试按钮，500 不透后端原文
- [ ] 空态有引导按钮
- [ ] 表单按钮防重复（loading + disabled）

### 工程
- [ ] 组件 ≤ 300 行；CSS 无全局裸类名（BEM/Modules）
- [ ] 无 console.log / debugger / TODO / 测试文案残留
- [ ] 路由有中文 title；界面无英文报错
- [ ] `npm run lint` 零 error（自己跑，别只信 AI）

### 提交
- [ ] 分支名 `feat/fe-<页面>-<简述>`
- [ ] PR 描述含：做了什么 / 自查结论 / **页面截图或 GIF**（没截图队长直接关 PR）

## 队长侧规则（公示）

- PR 无截图 → 直接关，不看代码
- ❌ 阻断项未清就 merge → 该成员下一次 PR 强制全量复查
- 9-01 后只接受 `fix:` 前缀 PR
