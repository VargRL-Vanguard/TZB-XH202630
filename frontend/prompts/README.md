# 前端 AI 协作文档包（导读）— 先读我

> 本目录是前端整改的**任务下发区**。每个角色一份专属文档，打开就能干活。
> 分工总表见项目根目录 `前端整改任务分工表.md`（军令状，死线与问责以它为准）。

## 三步开工法

1. **找到你的角色文档**（见下表），从头到尾读一遍（5 分钟）
2. **复制文档里的「开工提示词」整段**，粘贴给你的 AI 编程助手（TRAE / Cursor / Claude 等）
3. AI 会先读项目文件、回答自查题，然后带着你逐项完成任务清单，**并在正确节点提醒你做只有你能做的手操**（浏览器实测、截图发群、git 提交等）
