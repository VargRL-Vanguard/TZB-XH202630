## 任务清单

### 阶段一：基建（8-19，阻塞全队）

- [ ] `frontend/` 脚手架：Vite + Vue3 + TS + Element Plus 按需引入 + ECharts 按需引入（`echarts/core`）+ ESLint/Prettier
- [ ] `src/router/index.ts`：全路由表 + **守卫**（未登录访问业务页 → 跳 `/login`；404 页中文 + "返回首页"按钮；切换路由同步 `document.title`）
- [ ] `src/api/request.ts`：自动带 `Authorization: Bearer <token>`；统一拦截 `{code,message,data}` 解包；401 → 清 token 跳登录；500 → "服务异常，请稍后重试"；超时与网络错误的兜底
- [ ] `src/stores/`：`auth.ts`（token/userId/role）、`agentEvents.ts`（WS 事件流按 traceId 分组，供大屏与回放器共享读取）
- [ ] `src/ws/client.ts`：连接 `ws://127.0.0.1:8000/ws?token=xxx`；30s 心跳 ping；断线指数退避重连（1s/2s/4s…最大 30s）；重连中页面顶部黄色横幅、成功后自动消失；收到未知 type 只 console.debug 不报错；乱序事件容错
- [ ] `.env.development`：`VITE_API_BASE=http://127.0.0.1:8000`、`VITE_USE_MOCK`
- [ ] 交付方式：基建完成后在群里发「基建完成」+ 目录结构截图，其他成员基于此开工

### 阶段二：登录 / 注册（P0-1，8-19）

- [ ] `views/Login.vue`：项目名 + 副标题「领域知识个性化生成与多智能体协同决策系统」+ 科技感渐变背景（录屏第一画面）；回车提交；按钮防抖防重复；错误**内联展示**（禁 alert）；`POST /api/auth/login` 成功存 token+userId+role，按角色跳转（student→仪表盘；teacher→学生列表；admin→质量看板）
- [ ] `views/Register.vue`：用户名/密码/姓名/角色下拉（student|teacher|admin）+ 可选 education/major；密码预校验 ≥8 位 + 字母 + 数字，失败按钮置灰 + 具体原因；`POST /api/auth/register`
- [ ] 登出：`POST /api/auth/logout` + 清本地态
- [ ] **真实联调**（A 区自家接口，联调不过没有借口）
