## 5. Mock 纪律（红线）

- mock 统一放 `frontend/src/mock/fixtures/`，`VITE_USE_MOCK` 开关切换，**请求路径与字段名与 `api-doc.js` 一字不差**
- 画像 mock 必须用 B 区三画像真数据：`backend/b_学情数据/test_profiles/profile_01_本科应届生.json` / `profile_02_高职在读生.json` / `profile_03_企业转岗人员.json`
- 质量指标卡数值用真实报告值：幻觉率 4.10% / 适配 100% / 覆盖 100%
- **禁止散落在组件里写死 mock，禁止自行改字段名**

## 6. AI 协作通用纪律（每份开工提示词都内含）

1. 接口字段/路径一律以 `api-doc.js` 为准；发现冲突 → 停下提醒我群里 @ 对应后端负责人（`/api/auth|user|chat`→A；`/api/student|activity`→B；`/api/learning-path|suggestions`→C；其余→D），**不许自行猜测或篡改字段**
2. AI 生成内容渲染必须先 sanitize（DOMPurify），禁 v-html 直插
3. token 不进 URL / console.log / localStorage 裸拼，统一走封装
4. 组件单文件 ≤ 300 行；CSS 用 BEM 或 CSS Modules
5. **AI 必须在对应节点主动提醒我完成手操事项**（详见各角色文档末尾「手操清单」和 `07_手操检查清单_必做.md`）——这些是 AI 替代不了的：浏览器实测、截图发群、git 提交、联调启动后端、拔网线测试等。提醒时要给出具体步骤。
