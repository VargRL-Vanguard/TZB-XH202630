# 11 队长验收与每日抽查（队长专用）

> 用途：队长每晚 21:00 抽查、Go/No-Go 检查点验收、双人验收签字的操作脚本。AI 帮你把「肉眼看看」变成「逐条对表」。

## 复制即用 · 每晚抽查提示词

```text
你是本项目的前端验收官。项目根 d:\TZB\TZB-XH202630，验收依据：
- frontend/prompts/08_接口契约速查表_字段级.md §8 每页 DoD
- frontend/prompts/07_手操检查清单_必做.md
- frontend/前端整改任务分工表.md（死线）

今晚是 2026-08-XX，请执行：
1. 根据当前日期对照 09 号应急预案的 Go/No-Go 检查点表，告诉我今晚该查哪个节点、Go 条件是什么
2. 我把成员今天发的截图/GIF 描述给你，你逐条对照对应页面的 DoD，输出：✅通过 / ❌未达（差哪条） / ⚠️无法判断（需要现场演示哪条）
3. 生成一段可直接发群的抽查结果通报：谁过了、谁没过、明天要补什么
4. 若有人连续 2 天未过同一节点，引用 09 号表的 No-Go 动作告诉我该执行什么

成员今日提交内容如下：（粘贴群消息/截图描述）
```

## 复制即用 · 页面验收签字提示词

```text
你是验收官。<成员名> 申请交付 <页面名>。请读 frontend/prompts/08_接口契约速查表_字段级.md §8 中该页面的全部 DoD 条目，逐条生成验收脚本：每条给出「操作步骤 → 预期现象 → 通过判定」。我会按脚本在浏览器实操，把实际结果（通过/不符合描述）回报给你，你输出最终验收结论：签字通过 / 整改清单（精确到条目）。整改后复验只测上轮失败项。
```

## 抽查操作流程（AI 之外你要亲手做的）

1. **随机点名**：从当日应交付的人里挑 1 个，从 08 号 §8 挑 1-2 条 DoD
2. **当场演示**：要求 10 分钟内发录屏或开屏幕共享 live 演示（防"截图是 AI 生成的/旧图"）
3. **对照记录**：把结果记进验收通报（模板见下）
4. **连坐规则**：演示不出来 = 当日进度作废 + 黄牌；同节点连续 2 天失败 = 触发 09 号 No-Go 动作
